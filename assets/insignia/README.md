# War Sim SVG source sheets

These source sheets preserve the twelve vector concepts integrated into the runtime insignia renderer in v0.4.3.2.2.

- `custom-campaign-emblems.svg`: Northern Shield, Iron Viper, Falcon Spear, Ember Watch, Night Anvil, Red Horizon.
- `operation-just-cause-unit-patches.svg`: 82d Airborne Division, 7th Infantry Division, 5th Infantry Division, 193d Infantry Brigade, 75th Ranger Regiment, 7th Special Forces Group.

Runtime rendering is implemented in `src/ui/insignia.js`; formation/campaign identity metadata lives in `src/data/formations.js`.
