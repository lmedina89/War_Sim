# War Sim SVG insignia source sheets

These source sheets preserve the twelve unit/campaign vector concepts integrated into the runtime insignia renderer beginning in v0.4.3.2.x. Historical formation identities remain tied to their canonical formations; fictional campaign emblems remain reserved for future canonical campaign/deployment records.

v0.4.3.3 separately redraws Army rank insignia programmatically in `src/ui/insignia.js` from official Army/TIOH grade-insignia structure. The rank symbols are original game-scale vector recreations rather than embedded raster scans.
